FAQ

What does ALS Converter do?

It creates a new Ableton Live 11.x-targeted copy of a Live 12 Set (.als). The tool analyzes version metadata and applies evidence-based Live 12 → 11 transforms when needed, then downloads a file such as Session_Live11_downgraded.als.

Does my .als file get uploaded?

No. Everything runs on this device in your browser. There is no upload to MontroneDSP servers, no accounts, and no cloud processing for this tool.

Which Live 11 versions can I target?

Live 11.2.11 (recommended for 11.2.x), Live 11.2.7, Live 11.3.21, Live 11.1, and Live 11.0.12. Choose the point release you actually run — Live 11.3 Sets will not open in Live 11.2.

Is it free and open source?

Yes — MIT License. Source: github.com/montronedsp/alsconverter. A portable Windows x64 app is available below.

Will every converted Set open in Ableton Live?

No guarantee. Converted Sets may fail to open or lose features. Keep backups. Static XML validation is not a confirmed open in Ableton Live. Not affiliated with Ableton AG.
