# Game engine logo sources

This directory includes SVG vector depictions of the Unreal Engine, Godot Engine and Unity logos.

- `unrealengine.svg` — Simple Icons (`icons/unrealengine.svg`)
- `godotengine.svg` — Simple Icons (`icons/godotengine.svg`)
- `unity.svg` — Simple Icons (`icons/unity.svg`)

**Source:** https://github.com/simple-icons/simple-icons
